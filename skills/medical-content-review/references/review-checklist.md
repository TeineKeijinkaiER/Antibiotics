## 0. どのクラスから見るか

患者に届く害の大きさ × 記載が陳腐化する速さ、で並べると次の順になる。

1. TDM対象薬（目標値は改訂が速く、外すと治療失敗か腎障害に直結）
2. 抗ウイルス薬・COVID-19治療薬（添付文書改訂が最も速い）
3. 腎機能別用量（境界値の扱いを誤ると全患者に効く）
4. 透析・CHDF（根拠が薄い領域なのに数値が独り歩きしやすい）
5. β-ラクタム（用量そのものは安定。ただし重症時用量は更新される）

## 1. TDM対象薬

**最優先。** 目標値はガイドライン改訂で変わり、古い値が資料に残りやすい。

| 確認点 | 見るべきこと |
| --- | --- |
| バンコマイシン | AUC-guided（目標AUC 400〜600 μg·h/mL, MIC=1）が基本方針として**先に**出ているか。トラフ値をガイドとした設計は腎障害リスクで非推奨。トラフ10〜15 は現行ガイドラインの目標値ではない |
| テイコプラニン | 目標トラフの**下限**。非複雑性MRSA感染症で15〜30 μg/mL、複雑性・重症で20〜40 μg/mL。下限10 は過小投与 |
| アミノグリコシド | ODD と MDD で目標値が別。ODD のトラフは薬剤ごとに異なる（GM <1、AMK <4）。概要表と詳細章で食い違いやすい典型 |
| ボリコナゾール | 目標トラフの下限・上限（有効性と肝障害・視覚障害のバランス）。資料内で複数の値が併存しやすい |
| 共通 | 初回TDM実施時期、採血タイミング（トラフは投与直前、透析患者は透析前）、ローディングの要否 |

**表示順が推奨の強さを伝えてしまう。** 目標値を並べるUIでは、
ガイドラインの第一推奨が先頭に来ているかを必ず画面で確認する。
データ配列の順序がそのまま表示順になっている実装は多い。

## 2. β-ラクタム系

| 確認点 | 見るべきこと |
| --- | --- |
| 重症時用量 | 髄膜炎・心内膜炎・発熱性好中球減少症の増量が漏れていないか |
| セファゾリン | 標準体格成人で 1g か 2g か。高体重例の増量規定 |
| カルバペネム | 添付文書の上限（IPM/CS は成人最大2g/日）を超えていないか |
| 持続・延長投与 | 実施する場合、対象薬・希釈・安定性の条件が書かれているか |
| ペニシリンG | カリウム負荷（1V中のK量）の注記 |

## 3. 腎機能別用量

| 確認点 | 見るべきこと |
| --- | --- |
| 指標 | CCr（Cockcroft-Gault）か eGFR か。**薬剤ごとに違う**。両者は交換不可 |
| 境界値 | 資料が固定3区分（>50 / 10-50 / <10）に丸めていないか。薬剤ごとに 30/50/60/90 など固有の境界を持つ |
| 「調整不要」 | 薬物動態上の結論か、単にデータが無いだけか。表示上で区別されているか |
| 腎機能亢進 | ARC（CCr ≧130）での増量規定の有無 |

## 4. 透析・CHDF

**根拠が薄い領域。** 原典自身が「参考」と断っていることが多い。
そのぶん、数値だけが独り歩きすると危ない。

| 確認点 | 見るべきこと |
| --- | --- |
| 除去性 | 分布容積が大きい薬・非腎排泄の薬は CHDF でほとんど除去されない。**増量の根拠が無いのに増量していないか** |
| 内部整合 | 「CCr <10 で調整不要」なのに「CHDF で倍量」は矛盾。CHDF の総クリアランスは正常腎機能を下回る |
| 上限 | 増量後の1日量が添付文書の上限を超えていないか |
| 透析日 | 透析後追加投与の要否、投与タイミング |

判断に使える一次資料：CRRT時の抗菌薬投与最適化に関する総説
（Front Pharmacol 2020, PMC7273837）に主要抗菌薬の除去性と要否の表がある。

## 5. 小児

| 確認点 | 見るべきこと |
| --- | --- |
| mg/kg の上限 | 「1日量として最大◯mg/kg」なのか「1回◯mg まで」なのか。体重あたりの上限を絶対量として扱う実装ミスが起きやすい |
| 分割回数 | 1日量だけで回数が欠落していないか |
| 年齢下限 | 新生児・低出生体重児の別記載 |
| 禁忌 | 8歳未満のテトラサイクリン系、キノロン系など |
| 成人情報の混入 | 腎機能別用量表・TDM設計など成人限定の情報が小児画面に出ていないか |

## 6. 抗ウイルス薬・COVID-19治療薬

**改訂が最も速い。** 前回レビューから半年でも変わる。

| 確認点 | 見るべきこと |
| --- | --- |
| 投与期間 | 短期治療薬では期間が用法・用量の一部。欠落は処方情報として不完全 |
| 年齢・体重の下限 | 適応拡大の改訂が入りやすい |
| 腎機能指標 | eGFR 基準か CCr 基準か |
| 併用禁忌 | リトナビル配合剤は相互作用が多い。参照先が示されているか |
| 開始期限 | 発症何時間以内か |

## 7. 抗真菌薬

| 確認点 | 見るべきこと |
| --- | --- |
| ボリコナゾール | 腎障害時の静注可否。「禁忌」と書いてよいのは添付文書の禁忌欄にある場合のみ。院内方針なら「院内運用上、原則使用しない」と書き分ける |
| ローディング | 初日と維持で用量が違う薬（VRCZ、CPFG、L-AMB）の初日量 |
| 相互作用 | アゾール系のCYP相互作用への導線 |

## 8. 投与速度・配合

| 確認点 | 見るべきこと |
| --- | --- |
| 単位 | 「◯g/hr 以上かける」のような、速度と時間を取り違えた表現になっていないか |
| 用量依存 | 投与量が増えたとき点滴時間が延びる規定になっているか（固定時間だと高用量で速すぎる） |
| 急速静注の可否 | ivPush 可否が薬剤ごとに書かれているか |

## 9. 適応外使用

| 確認点 | 見るべきこと |
| --- | --- |
| 対象集団 | 成人向けか小児向けか。原典で明示されないものを両方に出さない |
| 制度上の位置づけ | 保険審査上認められる事例なのか、完全な適応外なのか |
| 表示 | 通常用量と視覚的に区別され、意図せず目に入らないか |
