## 1. 階層の中身

### 階層A — 直近10年の査読論文／最新のガイドライン

修正の根拠にしてよいのはここだけ。ただし「ガイドライン」と名乗っていても、
学会の正式なCQ形式の推奨と、個人の総説では重さが違う。CQと推奨度がある文書を優先する。

**版を必ず確認する。** ガイドラインは数年ごとに改訂され、目標値が変わる。
「2016年版ではこうだった」という記憶で書かれた記載が、資料の中に残っていることは多い。
参照した版と参照日をレポートに書く。

### 階層B — 電子添文（添付文書）／PMDA

日本の保険診療と法的責任の基準。**臨床的な最適解ではない。**

添付文書は承認申請時の臨床試験に紐づくため、
- 適応症が実臨床より狭い
- 用量上限が国際標準より低い
- 小児・腎機能・妊娠の記載が「設定なし」で止まっている

ということが普通に起きる。「添付文書にないから誤り」と結論しない。

### 階層C — 教科書・総説

A・B が無い領域（CHDF時の投与量、稀な病態など）の裏付けに使う。
記載するときは「限られた報告に基づく」と明示する。

### 階層D・E — 古い論文、口伝

D（10〜20年前）は単独で修正根拠にしない。A の裏付けがあるときに補強として使う。
E（20年以上前、出所不明）は根拠として扱わず、§4 の未確認リストへ回す。

## 2. 資料が衝突したとき

### A と B が衝突する（頻出）

**両論併記する。** どちらかを消すのは誤り。

書き分けの型：

> 【国際的な推奨】左心系感染性心内膜炎では 8-12mg/kg 24時間毎
> （出典・推奨度）
> 【日本の保険適用】6mg/kg/day が最大。これを超える場合は査定・
> 副作用被害救済の対象外となりうるため、院内の適応外使用手続きに従う。

読み手が必要としているのは「どちらが正しいか」ではなく
「エビデンス上の最適」と「制度上の制約」の両方である。

### 原典（施設マニュアル）と A が衝突する

施設マニュアルは「その施設が決めたこと」なので、外部ガイドラインと違っていても
それ自体は誤りではない。ただし次を区別する。

| 状況 | 扱い |
| --- | --- |
| 施設が意図的に選んだ方針（狭域化、コスト、採用薬の都合） | 尊重する。ただし「院内方針」と明示し、ガイドラインとの差を注記する |
| ガイドライン改訂に追随できていないだけ | P1 として修正提案 |
| 目標血中濃度の下限がガイドラインより低い | **P1。過小投与＝治療失敗・耐性化なので過量と同じ重さ** |

見分け方：施設が意図的に選んだなら、普通は理由が書いてある。
理由の記載がなく、かつ古い版のガイドラインの値と一致するなら、追随漏れを疑う。

### 原典の中で衝突する

SKILL.md の Phase 2。外部資料で決着をつけてから、
原典側の修正文案とアプリ側の修正案を**両方**書く。
アプリだけ直すと次のデータ更新で再混入する。

## 3. 推奨度をそのまま引く

ガイドラインの推奨には強さがある。これを落として「ガイドラインが推奨」と書くと、
根拠の強さを誤って伝えることになる。

日本の感染症系ガイドラインで多い表記：

- **推奨度 I / A** — 実施するよう推奨する（強い根拠）
- **推奨度 II / B** — 実施を考慮してよい
- **推奨度 III** — 根拠が不十分。III-A は専門家の意見、III-C は否定的
- **エビデンスレベル** — メタ解析・RCT・観察研究・症例報告のどれか

レポートには推奨度まで書く。例：

> 抗菌薬TDM臨床実践ガイドライン2022 CQ4：
> 「非複雑性のMRSA感染症に対してはトラフ値15〜30 μg/mL を推奨する（I）」

## 4. 「エビデンス未確認」の扱い

根拠が見つからない記載は、**消さずに列挙する**。理由は3つ。

1. 黙って残すと、次回のレビューで同じ調査を最初からやり直すことになる
2. 黙って消すと、施設が意図して置いた記載を壊す可能性がある
3. 未確認であること自体が、次の調査の入口になる

レポートに節を立て、各項目に次を書く。

- どこに書かれているか
- どの資料を当たったか（当たって「無かった」ことに価値がある）
- 暫定的にどう扱うか（残す／注記を付けて残す／保留）

**残す場合は表示に注記を足すことを検討する。** 「限られた報告に基づく」
「院内の取り決め」と書いてあれば、読み手は根拠の強さを自分で判断できる。

よく未確認になる領域：

- CHDF・持続的血液濾過透析時の投与量（原典自身が「参考」と断っていることが多い）
- 小児の適応外使用
- 配合変化・投与速度の院内基準
- アンチバイオグラムに基づく経験的治療の選択

## 5. 出典の書き方

指摘1件につき、次を揃える。これが無い指摘は §4 へ回す。

```
根拠: <階層> <資料名> <版・発行年> <該当箇所（CQ番号・ページ）> <推奨度>
      <URL>
```

例：

```
根拠: A 日本化学療法学会・日本TDM学会「抗菌薬TDM臨床実践ガイドライン2022」
      CQ4（推奨度 I）
      https://www.chemotherapy.or.jp/uploads/files/guideline/tdm2022.pdf
```

**URL は必ず一次資料を指す。** 要約記事や二次情報のURLを書くと、
次回のレビューで検証できない。ガイドラインPDFは全文を落として
原文の推奨文を引用する（要約させない）。

## 6. 一次資料の入手先

| 資料 | 入手先 |
| --- | --- |
| 電子添文（添付文書） | PMDA医療用医薬品情報検索 https://www.pmda.go.jp/PmdaSearch/iyakuSearch/ |
| 日本化学療法学会ガイドライン | https://www.chemotherapy.or.jp/modules/guideline/ |
| 日本感染症学会ガイドライン | https://www.kansensho.or.jp/modules/guidelines/ |
| 厚労省 抗微生物薬適正使用の手引き | 厚生労働省サイト（版の更新に注意） |
| Minds（診療ガイドライン横断検索） | https://minds.jcqhc.or.jp/ |
| 査読論文 | PubMed / PMC。全文が PMC にあれば PDF を落として原文を引く |

ガイドラインPDFは大きいことが多い。取得したら
`extract_pdf_text.py` でテキスト化し、`grep` で推奨文を探すのが速い。
