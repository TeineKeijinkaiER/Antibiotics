# 抗菌薬投与マニュアル 第9版 医学的レビュー（原典修正点）

- レビュー日: 2026年8月28日
- 対象原典: `koukinyakutouyomanyual.pdf`（81ページ）
- 対象範囲: 初回監査で問題となった投与量、腎機能調節、TDM、抗ウイルス薬の記載、およびその周辺の明白な内部不整合・誤植
- 比較資料: 2026年8月28日時点のPMDA添付文書、日本化学療法学会・日本TDM学会「抗菌薬TDM臨床実践ガイドライン2022」

> **結論**: 前回指摘した事項のうち、IPM/CS、VCM点滴速度、VRCZ腎障害時の表現、オセルタミビル予防回数、COVID-19治療薬の投与期間欠落は原典にも存在する。原典を修正せずアプリだけ直すと、次回データ更新時に再混入するため、原典とアプリを同時に改訂する必要がある。

## 1. 修正優先度の定義

| 優先度 | 意味 |
| --- | --- |
| P0 | 過量投与、投与速度、禁忌判断など患者安全に直接影響する。公開・臨床利用前に修正必須 |
| P1 | 用法・期間・モニタリング方針の欠落または現行資料との重要な不一致 |
| P2 | 表記揺れ、境界値の曖昧さ、検索・転記ミスを誘発する誤植 |

## 2. 原典に確認された医学的修正点

### P0-1. Imipenem/Cilastatinの腎機能正常欄が過量

**原典箇所**

- p.10: `0.5g 6時間毎`（2g/日）
- p.16: CCr > 50mL/minで `1g 6時間毎`（4g/日）

同一原典内で矛盾し、p.16の用量は現行添付文書の成人最大量2g/日を超える。PMDA添付文書では、通常成人は0.5-1.0g/日を2-3回に分割し、重症・難治性感染症でも最大2g/日である。腎機能調節例はCCr 70-50で0.5g 12時間毎（重症時は1g 12時間毎まで）、CCr 50-30で0.25-0.5g 12時間毎、CCr 30-10で0.125-0.25g 12時間毎である。

**修正文案**

- p.16のIPM/CS行を一旦削除し、添付文書の区分に合わせて再構成する。
- 少なくとも `CCr > 50: 1g 6時間毎` は使用しない。
- 現行の3区分（>50 / 10-50 / <10）では添付文書の70、50、30、10の境界を安全に表現できないため、IPM/CS専用の区分表を設ける。

**根拠**

- PMDA「チエナム点滴静注用0.5g」添付文書（2026年2月改訂）  
  https://www.pmda.go.jp/PmdaSearch/iyakuDetail/170050_6139501D2105_1_05

### P0-2. Vancomycinの点滴速度表現が単位として不適切

**原典箇所**

- p.31: `点滴時間は1g/hr以上かける`

`g/hr`は速度の単位であり、「時間をg/hr以上かける」という文章は成立しない。「1g/hr以上」は速い投与を許容する指示にも読めるため危険である。PMDA添付文書は各投与を60分以上かけるよう規定している。

また、同ページにはローディングを一律「生食250mL、2時間」とする記載がある。25-30mg/kgで2gを超える場合、院内基準を最大1g/時とするなら2時間では速すぎる可能性がある。

**修正文案**

> 急速投与を避け、各投与は60分以上かけて点滴静注する。院内基準として最大投与速度を1g/時とする場合は「投与速度は1g/時以下（1g当たり60分以上）」とし、投与量に応じて点滴時間を延長する。

固定の「2時間」ではなく、総投与量に応じた最短投与時間を明示する。

**根拠**

- PMDA「バンコマイシン塩酸塩点滴静注用」添付文書（2025年11月改訂）  
  https://www.pmda.go.jp/PmdaSearch/iyakuDetail/730869_6113400A1227_1_05

### P0-3. Voriconazole静注をCCr 30以下で絶対的「禁忌」としている

**原典箇所**

- p.36: `CCrが30mL/min以下では投与禁忌。`

現行添付文書の「禁忌」欄に重度腎障害は含まれない。CCr <30mL/minでは「治療上やむを得ないと判断される場合を除き、注射剤は投与しない。経口剤を考慮」とされる。したがって、添付文書上の絶対的禁忌と表示するのは不正確である。

**修正文案**

> CCr <30mL/minでは、治療上やむを得ないと判断される場合を除き注射剤を投与せず、経口剤への切り替えを考慮する。CCr 30-50mL/minでは、注射剤の有益性が危険性を上回る場合のみ投与し、血清Crを監視する。

院内方針として使用禁止にする場合は、「添付文書上禁忌」ではなく「院内運用上、原則使用しない」と明記する。

**根拠**

- PMDA「ブイフェンド200mg静注用」添付文書（2026年6月改訂）  
  https://www.pmda.go.jp/PmdaSearch/iyakuDetail/672212_6179401F1026_3_13

### P1-1. Vancomycin TDMがトラフ中心で、AUC評価を限定しすぎている

**原典箇所**

- p.10、p.31: 通常Trough 10-15µg/mL、重症例Trough 15-20µg/mL
- p.31-32: AUCによるTDMを「MRSA菌血症で感染症科・ASTによる推奨がある場合」に限定

原典の参考文献に挙げられている「抗菌薬TDM臨床実践ガイドライン2022」は、Trough 15-20µg/mLでは腎障害リスクが高く、有効性と安全性を両立するトラフ目標を設定できないとして、AUC 400-600µg・h/mLを推奨している。原典の記載は院内運用としてはあり得るが、全国ガイドライン準拠の一般的推奨と誤解される。

**修正文案**

- AUC-guided TDM（目標AUC 400-600µg・h/mL）を基本方針として先に記載する。
- トラフ法を残す場合は「AUC評価が実施できない場合の院内代替運用」と位置付ける。
- Trough 15-20µg/mLは腎障害リスクが高いことを明記し、単独の目標として安易に提示しない。
- AUC評価をMRSA菌血症だけに限定する院内方針なら、その理由と適用範囲を明記する。

**根拠**

- 日本化学療法学会・日本TDM学会「抗菌薬TDM臨床実践ガイドライン2022」  
  https://www.chemotherapy.or.jp/uploads/files/guideline/tdm2022.pdf

### P1-2. Voriconazoleの目標Troughが原典内で不一致

**原典箇所**

- p.12: `Trough 2-4µg/mL`
- p.36: `Trough 1-4µg/mL`

同じ第9版内で目標域が異なる。アプリはp.36の1-4µg/mLを採用しているが、原典だけではどちらが院内合意値か判断できない。

**修正文案**

- 感染症科・薬剤部で現行の院内目標域を再承認し、p.12とp.36を統一する。
- 治療・予防、病型、毒性回避などで目標が異なる場合は、条件別に明記する。

### P1-3. Oseltamivir成人予防投与で「1日1回」が欠落

**原典箇所**

- p.14: `予防：1回75mg、7-10日間`

小児表p.44には「分1」と記載されているため、成人表の投与回数欠落である。

**修正文案**

> 予防：1回75mg、1日1回、7-10日間

### P1-4. COVID-19治療薬の投与期間が欠落

**原典箇所**

- p.12、p.18、p.40: Remdesivirは初日量・維持量のみで総投与期間なし
- p.14: Molnupiravir `1回800mg 1日2回`（5日間の記載なし）
- p.14、p.19、p.44: Nirmatrelvir/Ritonavirは1回量・回数のみ（5日間の記載なし）

短期治療薬では期間が用法・用量の一部であり、省略すると処方情報として不完全である。

**修正文案**

- Molnupiravir: `1回800mg、1日2回、5日間`
- Nirmatrelvir/Ritonavir: 各腎機能・体重区分の末尾に `5日間` を追記
- Remdesivir: 現行添付文書と院内適応に合わせて、標準期間、延長条件、総投与期間上限を明記

**根拠**

- PMDA「ラゲブリオ錠400mg／カプセル200mg」添付文書  
  https://www.pmda.go.jp/PmdaSearch/iyakuDetail/ResultDataSetPDF/170050_6250051M1028_1_11
- PMDA「パキロビッドパック600／300」添付文書  
  https://www.pmda.go.jp/PmdaSearch/iyakuDetail/672212_6250120X1027_1_10
- PMDA「ベクルリー点滴静注用100mg」添付文書  
  https://www.pmda.go.jp/PmdaSearch/iyakuDetail/230867_6250407D1020_1_09

### P1-5. Paxlovidの小児適応が2026年改訂に未対応

**原典箇所**

- p.44: `12歳以上かつ40kg以上`

これは第9版作成時点の記載であった可能性が高く、「当初からの誤り」ではなく添付文書改訂後の陳旧化である。2026年3月の添付文書では6歳以上かつ20kg以上へ拡大された。

**修正文案**

- 6歳以上かつ40kg以上: Nirmatrelvir 300mg + Ritonavir 100mg、1日2回、5日間
- 6歳以上かつ20kg以上40kg未満: Nirmatrelvir 150mg + Ritonavir 100mg、1日2回、5日間
- 6歳未満または20kg未満: 対象外
- 腎機能障害のある6歳以上40kg未満は臨床試験未実施である旨を併記

### P1-6. Paxlovidの腎機能指標をCCrとしている

**原典箇所**

- p.19: 腎機能障害時の経口薬表に `30 < CCr < 60mL/min`

現行添付文書はeGFR 30以上60未満を減量基準としている。Cockcroft-Gault CCrとeGFRは交換可能ではない。

**修正文案**

> 成人および6歳以上かつ40kg以上で、eGFR 30mL/min以上60mL/min未満：Nirmatrelvir 150mg + Ritonavir 100mgを1日2回、5日間。eGFR 30mL/min未満は推奨しない。

見出しもPaxlovidの行だけは「eGFR基準」と明記する。

## 4. 原典ではなくアプリ側の問題

以下は原典PDFの誤りとは分けて修正する。

1. 全薬剤を `CCr >50 / 10-50 / <10` の固定3区分に押し込め、自動ハイライトする実装。原典p.19は薬剤ごとに30、50、60、90など異なる閾値を保持している。
2. PaxlovidのeGFR基準をCockcroft-Gault CCrで自動判定する実装。
3. 原典の注意書きを表示しながら、該当しない範囲まで「この患者の腎機能では」と断定する表示。

薬剤ごとに `renalMetric`（CCr/eGFR）、数値境界、包含条件、透析条件を構造化する必要がある。

## 5. 改訂時の推奨手順

1. P0項目を原典PDFとアプリの双方で修正し、修正完了まで該当する自動用量表示を停止する。
2. 感染症科、薬剤部、ICT/ASTでVCM AUC運用とVRCZ目標域を再承認する。
3. COVID-19治療薬は投与期間、開始期限、年齢・体重、腎機能指標、主な併用禁忌の改訂日を一組で管理する。
4. 原典の各用量行に「参照した添付文書の改訂年月」を追加する。
5. 次版公開前に、全薬剤について原典、アプリJSON、画面表示の三者照合を行う。

## 6. レビュー範囲と限界

本報告書は、今回の初回監査で抽出された問題と、その周辺ページで確認できた明白な内部不整合・誤植をまとめたものである。全81ページ・全収載薬について、すべての効能、禁忌、相互作用、妊娠・授乳、肝機能補正まで逐語照合した完全監査ではない。臨床利用の承認には、全74薬剤を最新添付文書と照合する第2段階レビューが必要である。

## 7. 採用・実装状況（2026年8月28日）

本報告書のP0-P2指摘はすべて採用し、アプリのデータ・表示へ反映した。原典PDFそのものは編集せず、次版原稿で差し替えるべき修正文を本書に保持する。

### 医学情報

- IPM/CSの4g/日表示を削除し、添付文書上限2g/日と薬剤固有のCCr 70/50/30/10境界へ修正。
- VCMは各投与60分以上、最大1g/時を採用する場合は投与量に応じて延長。AUC 400-600を基本目標へ変更。
- VRCZはCCr 30mL/min未満を「絶対的禁忌」ではなく「やむを得ない場合を除き静注を避ける」へ修正し、トラフ目標を1-4µg/mLへ統一。
- オセルタミビル成人予防に1日1回を追記。
- レムデシビル、モルヌピラビル、ニルマトレルビル・リトナビルへ投与期間を追記。
- パキロビッドは2026年3月添付文書に合わせ、6歳以上・20kg以上へ更新し、腎機能判定をeGFRへ変更。

### 適応外使用の小児調査と表示方針

原典p.53-56には小児の適応外使用が存在するため、小児画面での全面非表示は行わない。原典で小児対象が明示された次の項目だけを小児画面に表示し、対象集団が明示されない項目は安全側に成人のみとして扱う。

- クラリスロマイシン小児用製剤の歯周組織炎・顎炎
- アモキシシリン・クラブラン酸（成人製剤・小児用製剤併記）の歯科領域適応
- セフェピムの小児肺炎
- アミカシンの非結核性抗酸菌症に対する小児用量
- ドキシサイクリンの小児リケッチア症
- アジスロマイシンの小児副鼻腔炎、百日咳、現行適応症に対する小児用量
- セファゾリンおよびアンピシリン・スルバクタムの小児高用量

### 画面・データ構造

- 適応外使用は成人・小児とも初期状態を折り畳みとし、クリック時のみ内容を表示。
- 適応外用量の緑色背景を廃止。
- 通常量、腎機能別用量、HD・CHDF用量を太字・背景付きカードで強調。
- 腎機能用量は薬剤ごとの指標（CCr/eGFR）と境界値を構造化し、該当範囲のみ自動強調。
- 菌種別アンチバイオグラムの抗菌薬略号から薬剤詳細へ遷移可能に変更。
