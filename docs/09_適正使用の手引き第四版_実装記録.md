# 抗微生物薬適正使用の手引き 第四版の一部採用

- 実装日: 2026年8月28日
- 情報源: 厚生労働省『抗微生物薬適正使用の手引き 第四版』医科・外来編／医科・入院編

## 採用範囲

- 急性下痢症
  - 成人・学童期以降: 外来編 p.36-43
  - 乳幼児: 外来編 p.78-82
  - 成人には主な原因食品と潜伏期間の表を掲載する。
  - 抗菌薬の適応・非適応は色付きタグにせず本文で説明する。
- 院内発症感染症
  - 入院編 p.24 表2「院内での頻度の高い感染症で問題となる代表的な原因微生物」
  - 単一菌に対応できる名称から当院アンチバイオグラムへ遷移する。

## 採用しない範囲

- 入院編の短期治療期間表は市中感染と院内感染を含むため、肺炎、尿路感染症、蜂窩織炎、菌血症等の独立した疾患ページへ混在させない。
- グラム陰性桿菌、口腔内常在菌、嫌気性菌等の総称を特定の1菌種へ誤ってリンクしない。
- 「抗菌薬を出さない」「条件付きで出す」等の色付き判断タグを設けない。

## UI上の安全対策

- 内服薬・注射薬・感染症別は、過去の選択状態にかかわらず毎回、成人／小児選択画面を経由する。
- 薬剤画面の成人／小児切替と患者条件入力を本文上部の大きな操作領域に配置する。
- 厚労省資料由来の画面では「適正使用の手引き」と明記し、編・ページを表示する。
