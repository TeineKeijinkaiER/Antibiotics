## 2. 医学的に修正した内容

### IPM/CS

- 原典p.16の `1g 6時間毎`（4g/日）は、現行添付文書の最大2g/日を超えるため不採用。
- 通常成人量を添付文書に合わせて `通常0.5-1g/day 分2-3、重症・難治性感染症では最大2g/day` に修正。
- CCr 70、50、30、10mL/minの薬剤固有境界を追加。
- 変更先: `src/data/drugs.betalactam.json`

### Vancomycin

- `点滴時間は1g/hr以上かける` を削除。
- 各投与60分以上、最大1g/時を採用する場合は総投与量に応じて延長する表現へ修正。
- AUC/MIC 400-600をTDMの基本目標へ変更。
- トラフ15-20µg/mLを一律に目標とすると腎障害リスクが高い旨を追加。
- 変更先: `src/data/drugs.antibacterial.json`、`src/components/Designer.tsx`

### Voriconazole

- CCr 30mL/min以下を「投与禁忌」とする表示を削除。
- CCr 30mL/min未満は「やむを得ない場合を除き注射剤を避け、経口剤を考慮」に変更。
- CCr 30-50mL/minは有益性が危険性を上回る場合のみ使用し、腎機能を定期確認する表示へ変更。
- トラフ目標を1-4µg/mLへ統一。
- 変更先: `src/data/drugs.antifungal-antiviral.json`、`src/components/Designer.tsx`

### 抗ウイルス薬

- オセルタミビル成人予防へ `1日1回` を追記。
- Molnupiravirへ5日間を追記。
- Remdesivirへ標準期間・延長条件・最大期間を追記。
- Nirmatrelvir/Ritonavirへ5日間を追記。
- Paxlovidを2026年3月添付文書に合わせて6歳以上・20kg以上へ更新。
- Paxlovidの腎機能判定をCockcroft-Gault CCrからeGFRへ変更。
- 変更先: `src/data/drugs.antifungal-antiviral.json`

## 3. 小児の適応外使用

### 小児画面へ表示する項目

原典で小児対象または小児用製剤が明示された次の項目に `populations` を設定した。

- Clarithromycin小児用製剤: 歯周組織炎・顎炎
- Amoxicillin/Clavulanate: 成人製剤・小児用製剤併記の歯科領域適応
- Cefepime: 小児肺炎
- Amikacin: 非結核性抗酸菌症の小児用量
- Doxycycline: 小児リケッチア症
- Azithromycin: 小児副鼻腔炎、百日咳、現行適応症の小児用量
- Cefazolin: 小児高用量
- Ampicillin/Sulbactam: 小児高用量

### データ上の扱い

- `OffLabelUse.populations?: PatientMode[]` を追加。
- `populations` 未指定レコードは安全側に成人のみとして扱う。
- 成人・小児の両方に明示されるレコードは `["adult", "pediatric"]`。
- データ検証に `adult` / `pediatric` 以外を拒否するチェックを追加。
- 変更先: `src/types.ts`、`src/data/offlabel.json`、`scripts/validate-data.mjs`

注意: `ol-amk-ntm` は成人用量と小児用量が同じ文字列に混在する。現在は両画面に同じ原典全文を表示している。将来は成人・小児レコードへ分割するとさらに明確になる。

## 5. 通常量・腎機能・透析表示

- 通常量と腎機能低下時セクションへ `.dosing-primary` を付与。
- 背景、境界線、太字見出しで主情報として強調。
- 腎機能用量の本文を太字化。
- HD・CHDFも同じカード内に残している。

### 薬剤固有の腎機能ルール

固定の `CCr >50 / 10-50 / <10` だけではPaxlovidなどを安全に扱えないため、以下を追加した。

```ts
type RenalDoseRule = {
  label: string;
  min?: number;
  max?: number; // [min, max) として判定
  dose: string;
};

type RenalRuleSet = {
  metric: "ccr" | "egfr";
  rules: RenalDoseRule[];
};
```

- `Drug.renalRules` があれば固定区分より優先。
- `renalRuleForPatient()` と `renalDoseForPatient()` で患者の該当用量を解決。
- eGFR必須薬でeGFRが未入力なら、CCrへ暗黙にフォールバックしない。
- 現在の個別ルール対象: IPM/CS、VRCZ、Oseltamivir、Paxlovid。
- 変更先: `src/types.ts`、`src/lib/calc.ts`、`src/components/DrugDetail.tsx`、`src/components/DrugLane.tsx`

## 7. TDM画面の列幅修正

ユーザーから「左タイトル列が幅を取りすぎ、右の数値列がつぶれる」と追加指摘があった。

- TDMの投与量表だけに `.tdm-dose-grid` を付与。
- 左の区分名列を `minmax(84px, 112px)` に制限。
- 右の用量・換算値列を `minmax(0, 1fr)` とし、縮小可能幅の問題を解消。
- 560px以下は既存仕様どおり縦積み。
- 600px画面で左列112px以下、右列が行幅の60%以上であることを自動検査へ追加。
- 変更先: `src/components/Designer.tsx`、`src/styles.css`、`scripts/check-tdm.mjs`

## 11. 次にClaude Codeが注意すること

1. 原典PDF自体は変更していない。次版マニュアルへ修正文を反映する場合は、`docs/07_医学的レビュー_原典修正点.md` を正本として使用する。
2. 本レビューは今回抽出した問題と周辺記載の監査であり、全74薬剤の効能・禁忌・相互作用まで網羅した完全監査ではない。
3. 医学データを変更するときは、最新PMDA添付文書または学会一次資料を再確認する。
4. `renalRules` を持つ薬剤では固定CCr区分へ戻さない。特にPaxlovidをCCrで自動判定しない。
5. `populations` 未指定の適応外使用を小児へ自動展開しない。
6. `.dose-conv` は患者条件から算出した通常用量の強調に使用する。適応外用量へ再利用しない。
7. TDM列幅は共通 `.renal-row` ではなく `.tdm-dose-grid` に限定して調整する。
8. 作業ツリーには今回の変更と生成物が未コミットで存在する。無関係な変更として破棄しない。
