## 1. このレーンは何か

### 1.1 目的

原典は当院『抗菌薬投与マニュアル 第9版』＝薬剤別。
そこに「感染症名から引く」入口を追加するのが本レーン。出典は別の文書である。

| ファイル（リポジトリ直下） | 正式名称 | 頁 | 構成 |
|---|---|---|---|
| `tekisei_out.pdf` | 厚労省『抗微生物薬適正使用の手引き 第四版 **医科・外来編**』 | 101 | **疾患別** |
| `tekisei_in.pdf` | 同『**医科・入院編**』 | 56 | **プロセス別**（疾患別の章がない） |

PDF からのテキスト抽出は `pdftotext -layout` で可能（poppler-utils はインストール済み。
未インストールの環境では `apt-get update && apt-get install -y poppler-utils`）。
**表は結合セルのせいでテキスト抽出だと分類ラベルの位置がずれる。**
表を読むときは必ず `pdftoppm -png -f <頁> -l <頁> -r 200 <pdf> <out>` で画像化して目視確認すること
（過去に AWaRe 分類でこの罠を踏み、4剤を誤分類したまま実装した事故がある）。

### 2.3 設計の要点（変更するときは理由を理解してから）

- **薬剤は文字列でなく `Drug.id` で持つ**（`RecommendedDrug.drugId`）。
  当院に採用のない薬剤は `drugId: null` にして名称のみ表示しリンクを張らない。
  **存在しない ID を書くと `validate-data.mjs` がビルドを落とす**（実際に壊して確認済み）。
- 起炎菌は `Organism.id`。タップで `OrganismDetail`（アンチバイオグラム画面）へ。
- 原典に経験的治療の記載がない疾患は、欄を空にせず `noRegimenNote` で
  「記載がない」ことを明示し、当院の薬剤ページへ送る。**他の出典で補わない。**
- 表は `tables` に構造化データとして持つ（画像で貼らない）。列数不一致はビルドが落ちる。
- `figures`（数値）は `<details>` で畳んである。FR-100-2 と FR-100-4 の両立のため。
- `RecommendedDrug.population` / `InfectionTable.population` で成人・小児を出し分け（FR-000-7）。

### 5.2 急性下痢症の治療（外来編 p.39）

推奨（原文）: **急性下痢症に対しては、まずは水分摂取を励行した上で、基本的には対症療法のみ行うことを推奨する。**

- 成人ではウイルス性・細菌性に関わらず自然軽快することが多い
- バイタルサインや起立性低血圧の有無等で脱水の程度を評価し、補液の必要性を検討する。可能な限り経口で水分摂取
- 経口補水では糖分・ナトリウム・カリウム等の電解質を含んだ飲料を摂取することが重要
- 重度脱水の乳幼児や高齢者では経口補水液（ORS）が推奨される。成人では多くの場合、
  果物ジュースやスポーツドリンク等で十分（塩分含有量が少ない場合は適宜塩分摂取）
- **重症例または海外渡航歴のある帰国者（渡航者下痢症）を除いて抗菌薬投与は推奨されない**（JAID/JSC・ACG）
- JAID/JSC の指針では、一定の場合に抗菌薬投与を考慮するとされている
  → **p.39 以降に条件の列挙が続く。未抽出なので実装時に確認すること**

小児の急性下痢症は外来編 p.78–82（10章）。表6「小児の嘔吐の鑑別疾患」が p.79 にある。**未抽出。**

| 創部感染症（表層） | 黄色ブドウ球菌（MSSA・MRSA）、表皮ブドウ球菌 |
| 創部感染症（深部） | 腸球菌（E. faecalis 等）、黄色ブドウ球菌、グラム陰性桿菌 |

出典表記: JANIS 2023年1〜12月公開情報参照

**経験的治療の考え方（同 p.24 本文の要約）**

- 極めて重症なら想定されるすべての微生物をカバーし、培養結果判明後に狭域へ de-escalation
- 敗血症性ショックでは適切な培養を採取して1時間以内の投与が推奨（SSCG 2021）
- 発熱していても重症でなければ、培養採取の上で抗菌薬を投与せず経過観察、
  または狭域薬で開始し後日の培養結果で変更する戦略も取り得る
- 経験的治療の選択は薬剤耐性菌の頻度等、地域・施設間の差が大きい。
  **院内ガイドラインがある場合はそれを参照する** ← 当院版としてはアンチバイオグラムへ送る接続点
