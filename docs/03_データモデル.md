# データモデル設計

- 版: 0.1
- 原典: 手稲渓仁会医療センター『抗菌薬投与マニュアル 第9版』

コードとデータを完全分離するため、医薬品情報は JSON ファイル群として管理する。
全レコードは `source`（原典ページ）を必須とし、これが無いものはビルドを通さない。

---

## 1. エンティティ関連

```
Drug (薬剤)
 ├─ DosingRule[]        用量レコード （成人/小児 × 経路 × 腎機能 × 適応）
 ├─ TdmProfile?         TDM 情報（目標濃度・採血タイミング）
 ├─ Formulation[]       製剤情報（規格・薬価・投与時間・配合変化）
 └─ OffLabelUse[] ──┐
                    ├─ Disease (疾患)   ← 双方向検索の要
Organism (菌)        │
 └─ Antibiogram[]    │  菌 × 抗菌薬 × 入院/外来 の感受性率
                     │
SurgicalProphylaxis ─┘  領域 × 臓器 × 推奨薬
```

## 2. Drug（薬剤マスタ）

```jsonc
{
  "id": "cefepime",
  "genericName": { "en": "Cefepime", "ja": "セフェピム" },
  "brandNames": ["セフェピム塩酸塩静注用1g"],
  "abbr": "CFPM",
  "class": "第4世代セフェム系",
  "category": "antibacterial",        // antibacterial | antifungal | antiviral | antituberculous | anthelmintic
  "aware": "Watch",                   // Access | Watch | Reserve | NotRecommended | null
  "requiresApplication": false,       // 使用申請書の要否 (p.8)
  "consultSpecialist": false,         // 「専門家にコンサルテーション」注記
  "renalAdjustmentNotRequired": false,// 原典★印: 腎機能低下時も常用量可
  "searchAliases": ["cefepime", "セフェピム", "CFPM", "マキシピーム", "第4世代"],
  "source": { "edition": 9, "pages": [11, 16, 39, 68] }
}
```

## 3. DosingRule（用量レコード）

用量は「成人/小児 × 経路 × 腎機能区分 × 適応」で一意に決まる。原典で複数箇所に散っている情報を、
すべてこの単一の形に正規化する。

```jsonc
{
  "drugId": "cefepime",
  "population": "adult",              // adult | pediatric | neonate
  "route": "iv",                      // iv | po | im | inhalation | topical
  "renalStatus": "ccr_gt_50",         // normal | ccr_gt_50 | ccr_10_50 | ccr_lt_10 | hd | chdf | 数値レンジ
  "indication": null,                 // null=一般. "meningitis" 等の適応キー
  "indicationLabel": null,            // "髄膜炎" など表示用
  "dose": {
    "kind": "fixed",                  // fixed | perKg | perKgPerDay | units | custom
    "amount": 1, "unit": "g",
    "interval": "8h",
    "maxPerDose": null, "maxPerDay": null
  },
  "weightBasis": null,                // actual | ideal | adjusted  (mg/kg のとき必須)
  "offLabel": false,                  // 原典の「＊適応外使用」
  "note": null,
  "source": { "edition": 9, "pages": [11] }
}
```

同一薬剤の別レコード例（適応で分岐）:

```jsonc
{
  "drugId": "cefepime", "population": "adult", "route": "iv",
  "renalStatus": "ccr_gt_50",
  "indication": "febrile_neutropenia_or_pseudomonas",
  "indicationLabel": "発熱性好中球減少症・緑膿菌感染",
  "dose": { "kind": "fixed", "amount": 2, "unit": "g", "interval": "12h" },
  "source": { "edition": 9, "pages": [11] }
}
```

mg/kg 系（小児）の例:

```jsonc
{
  "drugId": "vancomycin", "population": "pediatric", "route": "iv",
  "renalStatus": "normal", "indication": null,
  "dose": { "kind": "perKgPerDay", "amount": 40, "unit": "mg", "dividedInto": "2-4" },
  "weightBasis": "actual",
  "source": { "edition": 9, "pages": [39] }
}
```

`renalStatus` に「投与量・間隔の調整不要」が対応する場合は、レコードを作らず Drug 側の
`renalAdjustmentNotRequired: true` で表現する。原典に記載がない組み合わせはレコードを作らない
（アプリは「原典に記載なし」と表示する）。

## 6. OffLabelUse + Disease（適応外使用）

双方向検索の中核。`drugId` と `diseaseIds` の両方にインデックスを張る。

```jsonc
{
  "id": "offlabel-clindamycin-nf",
  "drugId": "clindamycin",
  "productLabel": "クリンダマイシンリン酸エステル注射液600mg",
  "category": "indication",     // indication | indication_and_dosage | dosage
  "diseaseIds": ["necrotizing_fasciitis", "toxic_shock_syndrome"],
  "dosageText": null,
  "source": { "edition": 9, "pages": [53] }
}
```

```jsonc
{
  "id": "offlabel-pcg-brain-abscess",
  "drugId": "benzylpenicillin",
```

## 8. Antibiogram（感受性率）

```jsonc
{
  "year": "令和8年度",
  "period": "2025-01 〜 2025-12",
  "setting": "inpatient",             // inpatient | outpatient
  "organismId": "e_coli",
  "isolates": 583,
  "susceptibility": {
    "ABPC": 66, "PIPC": 75, "SBT/ABPC": 76, "TAZ/PIPC": 96, "MEPM": 100,
    "CEZ": 92, "CMZ": 96, "CTRX": 98, "CAZ": 98, "CFPM": 99,
    "AMK": 99, "CPFX": 78, "LVFX": 73, "ST": 91
  },
  "annotations": ["ESBL産生菌の割合：17%"],
  "source": { "edition": 9, "pages": [70] }
}
```

表示ルール（原典 p.70 凡例）:

| 感受性率 | 色 |
| --- | --- |
| 80–100% | 緑 |
| 50–80% | 黄 |
| 0–50% | 赤 |
| データなし | グレー（空欄） |

算出定義（p.72）: `感受性株数 ÷ 対象株数 × 100`。`I`（Intermediate）は感性株に含めない。

## 10. データ整備の進め方

| 手順 | 内容 | 注意 |
| --- | --- | --- |
| 1 | 薬剤マスタの確定（採用薬一覧 p.65-68 を起点） | 略語・商品名の表記を薬剤部と統一 |
| 2 | 成人静注・成人経口の用量を投入（p.10-15） | 適応別分岐を `indication` に分解 |
| 3 | 腎機能・透析・CHDF を投入（p.16-22） | 「調整不要」はフラグで表現しレコードを作らない |
| 4 | 小児用量を投入（p.38-44） | 「設定なし」は明示レコードとして持つ（空欄と区別する） |
| 5 | TDM プロファイル（p.31-36） | 計算ロジックのテストケースを同時に作成 |
| 6 | 適応外使用 + 疾患マスタ（p.52-56） | 疾患の別名は臨床側の監修が必須 |
| 7 | アンチバイオグラム（p.70-71） | **PDFからではなく作成元のExcelから取り込む**（PDFはテキスト抽出で列が崩れる） |
| 8 | 周術期・製剤情報・その他章 | — |
| 9 | 全件を原典と突合するダブルチェック | 薬剤部・感染制御管理室 |

### 品質ゲート（CI で自動化）

- JSON Schema 検証を通過すること
- 全レコードに `source.pages` が存在すること
- `dose.kind = "perKg"` のレコードに `weightBasis` が存在すること
- Antibiogram の感受性率が 0–100 の整数であること
- 薬剤 ID の参照切れ（OffLabelUse → Drug、Antibiogram → Organism）がないこと
