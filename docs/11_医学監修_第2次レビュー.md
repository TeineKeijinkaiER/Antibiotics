## 2. 指摘事項

### P1-1. テイコプラニンの目標トラフ下限が現行ガイドラインを下回る【適用済み】

**所在**: `src/data/drugs.antibacterial.json` teicoplanin.tdm／原典 p.33

**現在の記載**（修正前）

- トラフ **10-30** µg/mL（条件なし）
- 重症例（感染性心内膜炎、骨関節感染症等）トラフ 20-30 以上を考慮

**問題**

原典自身が矛盾している。

| 原典箇所 | 目標トラフ |
| --- | --- |
| p.10（注射抗菌薬 一覧表） | **15-30** µg/mL |
| p.33（テイコプラニンの初期投与量） | **10-30** µg/mL |

アプリは p.33 を採用していたため、**下限が10 µg/mL** になっていた。
抗菌薬TDM臨床実践ガイドライン2022 は非複雑性MRSA感染症に対して
トラフ **15〜30 µg/mL** を推奨度 I で推奨しており、10〜15 µg/mL の範囲は
有効性が担保されない。抗菌薬の過小投与は治療失敗と耐性化に直結するため、
過量と同じ重さで扱う必要がある。

また「20-30 以上」は日本語として範囲の上限が定まらず、
どこまで上げてよいかが読み取れない。ガイドラインは複雑性・重症例に
20〜40 µg/mL という上限付きの範囲を示している。

**根拠**

- A 日本化学療法学会・日本TDM学会「抗菌薬TDM臨床実践ガイドライン2022」
  **CQ4（推奨度 I）**「非複雑性のMRSA感染症に対してはトラフ値15〜30 μg/mL を推奨する」
  同 CQ10「複雑性感染症や重症例では20〜40 μg/mL とする」
  https://www.chemotherapy.or.jp/uploads/files/guideline/tdm2022.pdf
- 同ガイドラインは小児についてのみ 10 µg/mL 以上を目標としており（CQ8）、
  原典 p.33 の「10」は小児の値の混入である可能性がある

**修正（適用済み）**

- トラフ **15-30** µg/mL（非複雑性のMRSA感染症・CQ4 推奨度I）
- トラフ **20-40** µg/mL（複雑性感染症・重症例）
- 採用理由を `tdm.cautions` に明記し、原典p.33との差を追跡できるようにした

**原典側の修正案**: p.33 の「Trough：10-30μg/mL」を「Trough：15-30μg/mL」に、
「20-30μg/mL以上を考慮」を「複雑性感染症・重症例では20-40μg/mL」に改める。
p.10 は既に15-30なので変更不要。

### P1-2. バンコマイシンの目標値が、ガイドラインの推奨と逆順に表示されていた【適用済み】

**所在**: `src/data/drugs.antibacterial.json` vancomycin.tdm.targets

**問題**

docs/07 §7 は「AUC 400-600を基本目標へ変更」済みと記録しているが、
実際のデータ配列は次の順だった。画面は配列順にそのまま描画するため、
**条件のないトラフ10-15が第一の目標値として最初に表示され、
ガイドラインの推奨であるAUCが最後に表示されていた。**

```
1. ピーク  目標値なし
2. トラフ  10-15 µg/mL      ← 条件なし＝第一目標に見える
3. トラフ  15-20 µg/mL（AUC評価が利用できない場合の参考）
4. AUC     400-600（MRSA感染症の基本目標）  ← 最下段
```

トラフ 10-15 µg/mL はガイドラインの目標値ではない。同ガイドラインの
メタ解析では、10〜15 µg/mL は 10 µg/mL 未満と比べて臨床効果に有意差がない一方、
腎障害のリスクにはなると報告されている。

**根拠**

- A 同ガイドライン CQ「a. 目標AUCは400〜600 µg·h/mL（MIC=1）」
  「d. AUCガイドと比較し、トラフ値15〜20 µg/mLをガイドとした投与設計は
  腎障害のリスクがあり勧められない」
  「10〜15 µg/mL でさえ、＜10 µg/mL と比較した場合腎障害のリスクとなった（III-C）」

**修正（適用済み）** — 数値は変えず、順序と条件表記のみ変更した。

```
1. AUC     400-600（MRSA感染症の基本目標・ガイドライン2022・MIC=1）
2. トラフ  10-15 µg/mL（AUC評価が実施できない場合の院内代替運用）
3. トラフ  15-20 µg/mL（AUC評価が実施できない場合の参考。腎障害リスクが高く一律に狙わない）
4. ピーク  目標値なし
```

ブラウザ上で表示順を確認済み。

### P1-3. アジスロマイシンのCHDF用量が通常量の2倍【提案・未適用】

**所在**: `src/data/drugs.antibacterial.json` azithromycin.renal.chdf／原典 p.22

**現在の記載**: CHDF時 **500mg 12時間毎**（＝1000mg/日）

**問題**

アジスロマイシンは分布容積が 33.3 L/kg と極めて大きく、主に胆汁排泄される。
CRRTではほとんど除去されないため、**増量の薬物動態的な根拠がない。**

同じ原典の中でも矛盾している。

| 原典箇所 | 記載 |
| --- | --- |
| p.17（腎機能別） | CCr 10-50、CCr <10 とも「投与量・間隔の調整不要」 |
| p.21（透析） | 500mg 24時間毎、透析日は透析後に投与 |
| p.22（CHDF） | **500mg 12時間毎** |

CHDFの総クリアランスは正常腎機能を下回る。無尿で「調整不要」なのに
CHDFで倍量にする、という組み合わせは薬物動態上成立しない。
静注アジスロマイシンの承認用量は 500mg 1日1回であり、
1000mg/日はQT延長・肝障害のリスクを不必要に上げる。

**根拠**

- A/C Yang et al. "Recommendation of Antimicrobial Dosing Optimization During
  Continuous Renal Replacement Therapy", Front Pharmacol 2020（PMC7273837）
  Table 3 で azithromycin を "Drugs do not need adjustments"（CVVH/CVVHD/CVVHDF全て）に分類。
  Table 1 で Vd 33.3 L/kg、半減期68時間、胆汁排泄と記載。
  https://pmc.ncbi.nlm.nih.gov/articles/PMC7273837/
- B PMDA ジスロマック点滴静注用 電子添文（成人 500mg 1日1回）

**修正案**: CHDF時も **500mg 24時間毎（調整不要）** とする。原典 p.22 も同様に改める。

**適用しない理由**: 院内で決めた投与量表そのものの変更にあたる。
本アプリの表示内容は「当院の取り決め」であることを前提に読まれるため、
感染制御管理室・薬剤部の承認を経てから反映すべきと判断した。

### P1-4. クリンダマイシンのCHDF用量が電子添文の上限を超えうる【提案・未適用】

**所在**: `src/data/drugs.antibacterial.json` clindamycin.renal.chdf／原典 p.22

**現在の記載**: CHDF時 **600-900mg 8時間毎**

**問題**

上限側を採ると 900mg × 3回 = **2700mg/日** となり、
国内の電子添文が定める上限 2400mg/日 を超える。
クリンダマイシンは主に肝代謝で、CRRTでは除去されないため
（前掲 Front Pharmacol 2020 も "no dose adjustment is required" に分類）、
CHDFを理由に増量する根拠もない。

**修正案**: **600mg 8時間毎（調整不要）** とし、重症時に増量する場合は
1日2400mgを上限とする旨を併記する。

**適用しない理由**: P1-3 と同じ。院内の取り決めの変更にあたる。
