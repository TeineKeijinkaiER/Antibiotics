# 抗菌薬投与ナビ（仮称）

手稲渓仁会医療センター『抗菌薬投与マニュアル 第9版』をもとにした、院内向け抗菌薬投与量参照アプリ。

> **「薬剤名 or 菌名を打てば、その患者に投与できる量が3タップ以内で出る」**

## 現在のステータス

**Phase 0（MVP）実装済み・院内レビュー待ち。** 原典のデータ構造化とアプリ本体が動作します。

| | |
| --- | --- |
| 収載データ | 薬剤 74件／菌 40件／疾患 83件／適応外使用 68件／アンチバイオグラム 80行 |
| 品質ゲート | `npm run validate` — 全レコードの原典ページ必須、参照切れ・重複・値域を検査 |
| ビルド | `npm run build`（validate → typecheck → vite build の順に実行） |

## 動かす

```bash
npm install
npm run dev        # 開発サーバ
npm run validate   # データ品質ゲートのみ実行
npm run build      # 検証 + 型チェック + 本番ビルド
```

## 実装済みの機能

| ご要望 | 要件 | 実装 |
| --- | --- | --- |
| 抗菌薬名で検索し通常量がすぐ示される | FR-002 / FR-003 | 一般名（英・カナ）／商品名／略語／系統を横断検索。ひらがな・全角半角・長音の有無を吸収し、検索結果カードに通常量を直接表示 |
| 腎機能低下時の投与量がすぐわかる | FR-001 / FR-004 | Cockcroft-Gault で CCr を自動計算し、該当区分をハイライト・他区分を淡色化。HD/CHDF は CCr 区分より優先。記載のない区分は補完せず「原典に記載なし」と表示 |
| 成人と小児を入口で分ける | FR-000 | 起動時に必須選択（既定値なし）。選択中の集団の用量しか表示せず、切替時はトーストで通知。小児は体重未入力なら mg/kg 表記のみ |
| バンコマイシン等の投与設計 | FR-005 | VCM（eGFR区分・1日4g上限の警告・目標トラフ切替）、TEIC、GM/AMK（ODD/MDD/心内膜炎併用）、VRCZ（CCr≦30 で注射剤禁忌を自動警告） |
| 適応外使用を薬剤名・疾患名の双方から検索 | FR-006 | 「薬剤 × 疾患 × 用法用量 × 区分」の関係データに双方向インデックス。疾患は別名検索対応 |
| 菌名検索とアンチバイオグラム | FR-007 | 学名／短縮形／日本語名／略号／通称／カナで検索。入院・外来タブ、3段階ヒートマップ、検出株数の併記と30株未満の注意喚起 |

## 既知の要検証事項

- **アンチバイオグラム（p.70-71）は原データとの突合が未了。** PDF のテキスト抽出では表の列が崩れるため、
  ESBL産生率・MRSA/MRSE率を用いた算術整合チェック（例：S. aureus total の CEZ 67% = MSSA の CEZ 100% × (1 − MRSA率 0.33)）
  で主要行の列対応を検証しているが、**院内公開前に作成元 Excel との突合が必須**。
  アプリ内でもこの旨をバナー表示している（`antibiogram.json` の `meta.verified: false`）。
- イミペネム・シラスタチンは、標準投与量表（p.10、0.5g 6時間毎）と腎機能障害時の表（p.16、CCr>50 で 1g 6時間毎）の
  記載が異なる。原典どおり両方を保持し、薬剤詳細に注記している。
- プログラム医療機器（SaMD）該当性の確認、原典PDF同梱の可否、菌の日本語名リストの監修は未決（docs/02 §5 参照）。

## 免責

本アプリが示す投与量は当院でコンセンサスの得られた標準的な投与量であり、最終的な投与判断は主治医が行います。
使用時は添付文書を改めて精読し、必要に応じて感染症科・ICT／AST へコンサルテーションしてください。
本アプリは院内マニュアルの閲覧を支援するものであり、診断・治療方針の提示は行いません。
