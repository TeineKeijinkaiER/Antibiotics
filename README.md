# 抗菌薬投与ナビ（仮称）

手稲渓仁会医療センター『抗菌薬投与マニュアル 第9版』をもとにした、院内向け抗菌薬投与量参照アプリの企画・要件定義。

> **「薬剤名 or 菌名を打てば、その患者に投与できる量が3タップ以内で出る」**

## ドキュメント

| ファイル | 内容 |
| --- | --- |
| [docs/01_企画書.md](docs/01_企画書.md) | 背景・課題、コンセプト、想定ユーザー、フェーズ分割、技術方針、リスク |
| [docs/02_要件定義書.md](docs/02_要件定義書.md) | 機能要件（FR-000〜FR-010）、非機能要件、画面一覧、スコープ外、未決事項 |
| [docs/03_データモデル.md](docs/03_データモデル.md) | エンティティ設計、JSON構造、データ整備手順、品質ゲート |

## 実現する機能（ご要望との対応）

| ご要望 | 対応する要件 |
| --- | --- |
| 抗菌薬名で検索し通常量がすぐ示される | FR-002 / FR-003 |
| 腎機能低下時の投与量がすぐわかる | FR-001 / FR-004 |
| 成人と小児を入口で分ける | FR-000 |
| バンコマイシン等の投与設計 | FR-005 |
| 適応外使用を薬剤名・疾患名の双方から検索 | FR-006 |
| 菌名検索（学名・日本語名など複数表記）とアンチバイオグラム | FR-007 |

## 現在のステータス

企画・要件定義フェーズ。実装は未着手。

次のステップ: 要件定義のレビュー（医師・薬剤部・ICT/AST）→ データモデル確定 → 原典のJSON構造化 → MVP実装。

## 免責

本リポジトリの内容は院内マニュアルの電子化を目的とした設計文書である。
実際の投与判断は主治医が行い、使用時は添付文書を精読すること。
